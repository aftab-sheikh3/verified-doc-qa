# Information Security

## Passwords and accounts
Use the company password manager (1Password) for every work account. Passwords must be at least
14 characters. Multi-factor authentication is mandatory for email, source code and cloud consoles.

## Devices
Laptops must have full-disk encryption enabled and lock automatically after 5 minutes of
inactivity. Lost or stolen devices must be reported to the security team within 1 hour at
security@lumen-robotics.example.

## Data classification
Data is classified as Public, Internal, Confidential or Restricted. Restricted data (for example
customer robot telemetry and employee health records) may only be stored in approved systems and
must never be pasted into external AI tools.

## Phishing
Report suspicious emails with the "Report phishing" button in the mail client. The security team
runs a simulated phishing exercise every quarter.
