# Onboarding

## First week
New starters receive their laptop on day one and complete security training before getting
access to source code. Each new starter is paired with an onboarding buddy from another team.

## Probation
The probation period is 6 months. Notice during probation is 2 weeks on either side; after
probation it is 1 month for most roles and 3 months for directors.

## Tools
Engineering uses GitHub for source code, Linear for planning and Slack for chat.
